# Bit a Bit · Academia de Programación

Landing page demostrativa en HTML, CSS y JavaScript sin dependencias.

## Ejecutar

1. Descomprime `Academia_Programacion.zip`.
2. Abre `index.html` en el navegador. También puedes abrir la carpeta en VS Code.

## Archivos

| Archivo | Contenido |
| --- | --- |
| `index.html` | Estructura, textos, rutas, temarios y preguntas frecuentes. |
| `css/estilos.css` | Colores, tipografía, diseño adaptable y estilos de componentes. |
| `js/app.js` | Menú móvil y salida simulada del ejemplo de Python. |

Los colores principales se editan en `:root` del CSS. Los textos se editan en el HTML. El ejemplo muestra la salida esperada mediante JavaScript.
