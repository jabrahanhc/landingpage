03 / ANTES DE EMPEZAR

Preguntas frecuentes

¿Necesito experiencia previa?+

Las tres rutas parten de conceptos básicos. Puedes elegir según el proyecto que más te interese.

¿Qué necesito para practicar?+

Para desarrollo web, basta un navegador y un editor de texto. Para Python, puedes instalar el intérprete o usar un entorno en línea. Para la ruta de IA, necesitarás acceso a una herramienta de IA generativa.

¿Qué ruta me conviene para empezar?+

Elige Python si quieres practicar lógica, desarrollo web si quieres crear una página e IA aplicada si quieres aprender a usar y evaluar respuestas generadas por IA.
